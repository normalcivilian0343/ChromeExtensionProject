# ChromeExtensionProject
This is our chrome extension! It is called Article Annotater, including many features in one compact extension to make reading articles worry-free and enjoyable!

# How To Set It Up
To set this chrome extension up, there are just three simple steps!
1. Find the repository link and clone (using git clone or use a button in the code editor) it in any code editor
2. You can close this code editor, you will not need it once the cloning is done, and now open chrome extensions and toggle the button in the top right to say "Developer Mode"
3. Press load unpacked, find the Chrome Extension Project file in your files and click on it!
You now have full acess to our features!!

# What exactly does our project do?
While you open an article, it allows you to take notes, have an AI summary, define specific words, and save highlighted/annotated sentences, so that the next time you open up the article, you can see what exactly you wanted to remember! It creates an easy and usable workspace, instead of having a chopped up work ethic.


# How to use each feature!
To be able to use this version of our project, you need to be on an actual article/website that has text for you to read! PLEASE DO NOT USE EXTENSION ON THIS GIT RELEASE?REPO LINK<>

1. The highlight feature - you FIRST have to click on the highlight button and then you can proceed to highlight. DO NOT try to highlight without pressing the button! Tip: there will be a small black box that will say if highlight mode is activated or deactivated
2. The define word - like the highlight button, click on the button first and then double click a word to define it.
3. AI Summary - simply click the AI summary button and shortly (may take longer or shorter depending on how long and compact the article is), it will give you key points from the text, giving you a brief summary! PLEASE WAIT FOR THE AI SUMMERY TO POP UP, IT MAY TAKE A FEW MINUTES
4. Detect Article - simply click the button
5. Adding notes - type a note and press "save note" button near the bottom
6. Clear all data - press this button to reset everything - be sure not to accidently press it!
